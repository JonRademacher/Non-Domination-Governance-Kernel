## Commit Description

Adds the comparative analysis layer of the Non-Domination Governance Kernel.

This phase distinguishes domination from autonomy, capability, authority, personhood, frame structure, governance, and alignment. The goal is conceptual precision and portability.

The comparison modules prevent category collapse and clarify that the kernel classifies domination through frame authority and viable exit rather than through consciousness, capability, autonomy, or ontology.
