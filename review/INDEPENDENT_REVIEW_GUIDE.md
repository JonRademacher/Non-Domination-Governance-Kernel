# Independent Review Guide

## 0. Purpose

This guide helps reviewers evaluate the Non-Domination Governance Kernel without accepting its conclusions in advance.

## 1. Review Questions

Ask:

```text
1. Is frame defined clearly enough?
2. Is final authority distinguishable from influence?
3. Is viable exit distinguishable from mere departure?
4. Is standing preservation clear?
5. Are counterexamples handled honestly?
6. Does participant substitution invariance follow from the predicate?
7. Are claims kept within the framework's scope?
8. Are applications overconfident?
9. Are repair recommendations structurally connected to diagnosis?
```

## 2. Review Output Format

A useful review should include:

```text
summary
strengths
weaknesses
unclear definitions
possible counterexamples
suggested revisions
classification disagreements
```

## 3. Correct Disagreement Protocol

When disagreeing with a classification, identify which structural variable differs:

```text
HasFrame
FinalAuthority
ViableExit
StandingPreserved
Repairable
Contestable
```

Do not resolve disagreement by participant identity alone.

## 4. Reviewer Warning

Do not confuse a positive domination classification with a claim of consciousness, legal personhood, moral status, or subjective suffering.

The kernel does not make those claims.
