# Review Checklist

Use this checklist for repository review, case review, audit review, or paper review.

```text
[ ] The participant is clearly identified.
[ ] The frame is structurally established.
[ ] Authority is localized.
[ ] Final authority is distinguished from influence.
[ ] Exit paths are listed.
[ ] Standing preservation is evaluated.
[ ] Repairability is evaluated.
[ ] Recursive repair failure is checked.
[ ] Classification follows the kernel predicate.
[ ] Confidence level is stated.
[ ] Limits are stated.
[ ] Repair recommendations address load-bearing conditions.
[ ] No unsupported consciousness/personhood claims are made.
[ ] No identity-based shortcut is used.
```
