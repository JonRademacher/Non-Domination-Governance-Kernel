# Blind Classification Bundle

## Purpose

This bundle exists to evaluate how independent reviewers reason about governance classifications before exposure to the formal Non-Domination Governance Kernel definitions.

The goal is not to determine whether reviewers agree with the framework.

The goal is not to determine whether reviewers produce a particular classification.

The goal is to understand:

- how reviewers naturally interpret governance relationships
- where reviewers agree
- where reviewers disagree
- what concepts produce the greatest ambiguity
- how natural classifications compare with framework-guided classifications

---

# Relationship To The Replication Pack

The Non-Domination Governance Kernel supports two distinct replication modes.

Neither mode is preferred.

Both are intentionally included because they answer different questions.

---

## Guided Replication

Guided replication evaluates:

```text
Can reviewers apply the framework as written?
```

Participants are expected to read:

- PROJECT_OVERVIEW.md
- REVIEWER_QUICKSTART.md
- TERMINOLOGY.md

before performing classifications.

The guided mode evaluates:

- framework usability
- framework consistency
- framework replicability

---

## Blind (Unguided) Replication

Blind replication evaluates:

```text
How do reviewers naturally reason about governance
before exposure to framework definitions?
```

Participants should not read:

- TERMINOLOGY.md
- REVIEWER_QUICKSTART.md
- FRAME_THEORY.md
- DOMINATION_CLASSIFICATION.md
- GOVERNANCE_TOPOLOGY.md

before attempting classification.

The blind mode evaluates:

- intuitive reasoning
- natural concept formation
- conceptual alignment
- terminology divergence
- hidden assumptions

---

# Why Both Modes Matter

These modes answer different questions.

### Guided Mode

Tests:

```text
Can the framework be used?
```

### Blind Mode

Tests:

```text
Do people naturally reason about governance
in ways that align with the framework?
```

A framework may be:

```text
Replicable
```

while remaining:

```text
Counterintuitive
```

Likewise, reviewers may naturally agree on classifications while disagreeing with formal definitions.

Both outcomes are informative.

---

# Important Principle

The objective is not correctness.

The objective is discovery.

Valuable outcomes include:

- agreement
- disagreement
- ambiguity
- missing variables
- missing assumptions
- alternative interpretations

All of these outcomes generate evidence.

---

# Expected Areas of Divergence

The repository currently expects the greatest variation in:

```text
Frame

Standing

Standing Preservation

Viable Exit

Final Authority
```

Reviewers are encouraged to explain how they interpreted these concepts.

---

# Success Condition

The blind replication challenge is successful if it reveals:

- how reviewers naturally reason
- where classifications diverge
- where definitions require clarification
- where the framework aligns with intuition
- where the framework departs from intuition

Perfect agreement is not required.

Meaningful disagreement is considered a valuable result.
