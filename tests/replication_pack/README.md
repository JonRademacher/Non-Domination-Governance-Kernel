# Replication Pack

## Purpose

The purpose of this replication pack is to evaluate whether independent reviewers can apply the Non-Domination Governance Kernel consistently.

The goal is not to determine whether the reviewers reach a specific answer.

The goal is to identify:

- agreement
- disagreement
- ambiguity
- missing variables
- classification failure

within the framework.

---

## Instructions for Reviewers

Before attempting classification, read:

1. PROJECT_OVERVIEW.md
2. REVIEWER_QUICKSTART.md
3. TERMINOLOGY.md

Do not read repository issues.

Do not consult repository authors.

Attempt classification independently.

---

## Required Output

For each scenario, determine:

- Participant
- Frame
- Final Authority
- Viable Exit
- Standing Preservation
- Repairability
- Classification
- Confidence Level

---

## Important Rule

If information appears insufficient for a classification:

```text
State what information is missing.
```

The correct answer may be:

```text
Unknown
Low confidence
Insufficient information
```

---

## Evaluation Goal

The replication challenge succeeds if:

- independent reviewers can explain their reasoning
- disagreements identify specific variables
- classification differences expose possible weaknesses

The challenge does not require reviewers to agree.
