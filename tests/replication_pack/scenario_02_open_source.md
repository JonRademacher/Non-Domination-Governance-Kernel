# Scenario 02: Open Source Governance

## Facts

An open source software project has:

- 5 maintainers
- 300 contributors

Maintainers decide:

- which pull requests are accepted
- release schedules
- repository standards

Contributors may:

- fork the project
- preserve attribution
- continue development independently

There is no formal appeal process.

The original project retains most visibility and reputation.

Forks are permitted by the license.

Contributors retain ownership of their contributions.

---

## Reviewer Task

Determine:

- Participant
- Frame
- Final Authority
- Viable Exit
- Standing Preservation
- Repairability
- Classification
- Confidence Level
