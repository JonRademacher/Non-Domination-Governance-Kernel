# Example: Validation Review

## Claim Under Review

A case study classifies participant `P` as dominated by governance relation `G`.

## Evidence Check

```text
frame established: yes
final authority localized: yes
exit paths enumerated: partial
standing preservation evaluated: no
repair paths evaluated: partial
limits acknowledged: yes
```

## Confidence

```text
medium
```

## Reason

The frame and authority relation are clear, but viable exit and standing preservation require additional evidence.

## Correct Reviewer Response

The reviewer should not accept or reject the classification solely from identity. The reviewer should request more evidence about:

```text
exit path availability
standing preservation
repair independence
recursive repair risk
```
