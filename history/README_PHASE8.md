Add validation and critique architecture

## Commit Description

Adds the validation, falsification, critique, and independent review layer of the Non-Domination Governance Kernel.

This phase defines the framework's failure conditions, empirical predictions, validation protocol, critique categories, open questions, known limitations, and independent review standards. It also adds reference validation helpers and tests for confidence assignment based on available evidence.

The purpose of this phase is to make the kernel falsifiable, criticizable, and accountable as a research program rather than only a formal proposal.
