Add governance topology visualization library

## Commit Description

Adds the first visual communication layer for the Non-Domination Governance Kernel.

These topology diagrams represent the kernel's primary governance classes: open governance, bounded governance, repairable domination, closed domination, and recursive domination.

The purpose of this phase is to translate formal governance topology into reusable visual artifacts that can be used in papers, presentations, audits, governance reviews, teaching materials, and future implementations.
