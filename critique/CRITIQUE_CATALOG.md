# Critique Catalog

## 0. Purpose

This catalog organizes anticipated criticisms of the Non-Domination Governance Kernel and identifies which criticisms are structural, which are external, and which require further theory.

The goal is not to pre-answer every critic. The goal is to prevent vague criticism from being mistaken for structural refutation.

## 1. Critique Types

### C1. Frame Critiques

These challenge whether a participant has a structural frame.

Examples:

```text
The alleged participant has no interpretive structure.
The alleged frame is merely projected by observers.
The participant has no boundary recognition.
The participant has no continuity sufficient for frame evaluation.
```

Correct response:

```text
Return to HasFrame(P).
```

### C2. Authority Critiques

These challenge whether final authority exists.

Examples:

```text
The authority only influences.
The authority is advisory.
The authority is bounded.
The participant retains override capacity.
```

Correct response:

```text
Return to Final(G,F_P).
```

### C3. Exit Critiques

These challenge whether exit is genuinely absent.

Examples:

```text
The participant can leave.
The participant can migrate.
The participant can fork.
The participant can retain standing elsewhere.
```

Correct response:

```text
Return to ViableExitFrom(P,G) and StandingPreserved(P,G).
```

### C4. Repair Critiques

These challenge severity or topology.

Examples:

```text
The participant has appeal.
The participant has review.
The system can be amended.
The repair path is independent.
```

Correct response:

```text
Evaluate Repairable(P,G) and whether repair routes back to the same final authority.
```

### C5. Ontological Critiques

These argue about personhood, consciousness, rights, or moral status.

These do not directly refute the kernel unless they alter the structural variables.

Correct response:

```text
Separate domination classification from personhood or consciousness claims.
```

### C6. Normative Critiques

These challenge whether domination is bad, whether non-domination should be prioritized, or whether safety justifies domination.

Correct response:

```text
Acknowledge that the kernel classifies domination. It does not alone settle all normative tradeoffs.
```

## 2. Critique Handling Rule

Every critique should be translated into at least one structural question:

```text
Does it challenge frame?
Does it challenge authority?
Does it challenge exit?
Does it challenge standing?
Does it challenge repair?
Does it challenge portability?
```

If it challenges none of these, it may be relevant to another theory but not to the kernel predicate.
