# Project Overview

The Non-Domination Governance Kernel is a structural framework for analyzing governance through frame authority, viable exit, standing preservation, contestability, and repairability.

Core predicate:

D(P,G) ⇔ Final(G,F_P) ∧ ¬ViableExitFrom(P,G)

The repository contains theory, topology, classification, repair architecture, audits, case studies, validation criteria, and critique infrastructure.
