# Design Principles

1. Structural Rather Than Phenomenological Analysis
   - Governance is analyzed through structure rather than subjective experience.

2. Blind Classification Before Identity Assignment
   - Classify first.
   - Identify second.

3. Governance Distinguished From Domination
   - Authority alone is insufficient for domination.

4. Viable Exit Matters
   - Exit must preserve standing.

5. Repair Preferred To Elimination
   - Governance failures should trigger repair when possible.

6. Explicit Authority Localization
   - Final authority should be identifiable.

7. Cross-Domain Portability
   - The framework should translate across domains.

8. Falsifiability
   - The framework must expose attack surfaces and counterexamples.
