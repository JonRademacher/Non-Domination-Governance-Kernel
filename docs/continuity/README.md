# Continuity Layer

This folder contains artifacts intended to preserve project continuity, decision history, context recovery, collaboration state, and review state across releases and conversations.

These documents are not part of the formal Non-Domination Governance Kernel.

They exist to reduce reconstruction cost and improve frame recoverability.

Recommended reading order:

1. CURRENT_STATE.md
2. SESSION_RESUME_PROTOCOL.md
3. DECISION_LOG.md
4. EXPERIMENT_LOG.md
5. RESUME_PROMPT.md
