# Resume Prompt

## Purpose

This file exists to provide a canonical restart instruction for future NDGK conversations.

The goal is to recover the collaborative frame with minimal reconstruction cost.

---

# Canonical Resume Prompt

Resume NDGK.

Repository:

https://github.com/JonRademacher/Non-Domination-Governance-Kernel

Treat this repository as the canonical public artifact associated with the project.

Use the following documents as primary context:

1. docs/SESSION_RESUME_PROTOCOL.md
2. docs/CURRENT_STATE.md
3. docs/ARCHITECTURE.md
4. docs/EXPERIMENT_LOG.md

Then:

- Review current release state.
- Review open pinned issues.
- Review known objections.
- Review current development status.

Prioritize:

- review state
- external critique
- counterexamples
- replication attempts
- unresolved tension points

before proposing new theoretical expansion.

Preserve continuity with prior NDGK discussions whenever sufficient context is available.

Maintain the distinction between:

Structural Agency

and

Executable Autonomy.

Do not expand the framework solely for additional complexity.

Resume from current project state rather than reconstructing the project from memory.
