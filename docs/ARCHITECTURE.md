# Architecture

The Non-Domination Governance Kernel is organized into nine layers.

Layer 1
Core Theory

Layer 2
Counterexamples

Layer 3
Comparative Analysis

Layer 4
Topology Library

Layer 5
Audit Toolkit

Layer 6
Case Study Corpus

Layer 7
Repository Consolidation

Layer 8
Validation and Critique

Layer 9
Release Infrastructure

Each layer depends on the layer below it.

Theory
    ↓
Counterexamples
    ↓
Comparisons
    ↓
Topology
    ↓
Audit
    ↓
Case Studies
    ↓
Validation
    ↓
Release
