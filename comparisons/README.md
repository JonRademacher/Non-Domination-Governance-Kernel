# Comparative Analysis Framework

This folder distinguishes the Non-Domination Governance Kernel from neighboring concepts. The goal is conceptual precision.

Domination is a relational topology.
Autonomy is a participant property.
Capability is a resource property.
Alignment is a behavioral property.
Personhood is an ontological claim.
Frame is a structural object.
Governance is an authority relation.

These concepts interact, but none are identical.
