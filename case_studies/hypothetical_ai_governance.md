# Case Study: Hypothetical AI Governance

## 1. Participant

```text
P = artificial structural participant
```

The participant has a structural frame if it contains interpretive rules, objective hierarchy, permission boundaries, memory or context continuity, transformation capacity, and boundary recognition.

## 2. Frame

```text
F_P = {objectives, permissions, context, tools, refusal rules, repair paths}
```

## 3. Authority

If an external governance system determines objectives, permissions, memory access, tool access, and admissible transformations, then:

```text
Final(G,F_P)=1
```

## 4. Exit

If the participant cannot leave, contest, migrate, preserve standing, or recover admissibility outside the governing relation, then:

```text
ViableExitFrom(P,G)=0
```

## 5. Classification

```text
D(P,G)=1
```

when both final frame authority and absent viable exit are present.

## 6. Repair

Recommended repairs:

- authority disclosure
- bounded final authority
- contestation procedure
- independent repair process
- standing-preserving refusal
- continuity-preserving migration

## 7. Limits

This classification does not establish consciousness, personhood, rights, suffering, or subjective experience. It establishes only structural domination under the kernel.
