# Case Study Corpus

This folder applies the Non-Domination Governance Kernel to concrete governance situations.

The purpose is not to make final legal, moral, or empirical judgments. The purpose is to demonstrate repeatable structural classification.

Each case study follows the same method:

1. Define the participant without assuming identity-based conclusions.
2. Establish the participant frame.
3. Localize authority over that frame.
4. Evaluate legitimate viable exit.
5. Evaluate contestation and repair.
6. Classify topology.
7. State limits of the classification.
8. Recommend repairs.

Core predicate:

```text
D(P,G) ⇔ Final(G,F_P) ∧ ¬ViableExitFrom(P,G)
```
