# Case Study: Social Media Platform Governance

## 1. Participant

```text
P = platform participant
G = platform governance system
```

## 2. Frame

The participant frame may include account identity, reputation, followers, content history, monetization status, moderation record, access privileges, and recommendation visibility.

## 3. Authority

If the platform has final authority over account status, visibility, monetization, moderation classification, and appeal admissibility, then:

```text
Final(G,F_P)=1
```

## 4. Exit

Exit must preserve standing to count as viable. Mere account deletion is not enough if it destroys reputation, history, identity, audience, or livelihood.

If no portability, appeal, migration, or standing-preserving exit exists:

```text
ViableExitFrom(P,G)=0
```

## 5. Classification

When final authority and absent viable exit are both present:

```text
D(P,G)=1
```

## 6. Repair

Recommended repairs:

- transparent moderation rules
- meaningful appeal process
- independent review for severe actions
- data portability
- reputation portability
- monetization appeal
- non-destructive account exit

## 7. Limits

This case study does not claim all platform governance is domination. It identifies domination risk where final frame authority combines with absence of standing-preserving exit.
