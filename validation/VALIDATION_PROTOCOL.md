# Validation Protocol

## 0. Purpose

This protocol defines how to evaluate whether a case study, audit, or critique properly applies the Non-Domination Governance Kernel.

## 1. Validation Questions

For every applied analysis, answer:

```text
1. Is the participant clearly identified?
2. Is the frame structurally established?
3. Is final authority localized?
4. Is viable exit evaluated?
5. Is standing preservation evaluated?
6. Is repairability evaluated?
7. Is classification derived from the predicate?
8. Are limits acknowledged?
9. Are repair recommendations structurally connected to the diagnosis?
```

## 2. Required Evidence Standard

A valid classification should cite or describe evidence for:

```text
frame components
authority locus
exit paths
standing preservation
contestability
repair paths
```

If evidence is unavailable, classify confidence as low.

## 3. Confidence Rules

### High Confidence

Use only when:

```text
frame is established
final authority is explicit
exit paths are enumerated
standing preservation is evaluated
repair paths are known
```

### Medium Confidence

Use when:

```text
frame and authority are clear
exit or repair is partially known
```

### Low Confidence

Use when:

```text
frame or authority is uncertain
exit is speculative
repair pathways are undocumented
```

## 4. Invalid Validation Practices

Invalid practices include:

```text
classifying from identity rather than structure
assuming non-human participants cannot have frames
assuming all authority is domination
assuming all constraint is domination
assuming local refusal equals viable exit
assuming memory continuity equals sovereignty
ignoring standing preservation
```

## 5. Replication Rule

A classification should be replicable by another reviewer using the same structural inputs.

If reviewers disagree, identify which input differs:

```text
HasFrame
FinalAuthority
ViableExit
StandingPreserved
Repairable
Contestable
```

Do not resolve disagreement by identity-based assertion.
