# Empirical Predictions

## 0. Purpose

The kernel is formal, but it should still generate observable expectations when applied to real governance systems.

This file states practical predictions that can be evaluated through case studies, audits, institutional records, user reports, policy review, and system design analysis.

## 1. Prediction: Exit Quality Predicts Domination Severity

Systems with destructive, non-portable, or standing-destroying exit paths should classify as more dominating than systems with standing-preserving exit.

Expected observation:

```text
account deletion only < data portability + appeal + migration
```

in terms of non-domination.

## 2. Prediction: Recursive Appeals Predict Persistent Domination

Systems where appeals route back to the same final authority should exhibit persistent domination debt.

Expected observation:

```text
appeal_to_same_authority ⇒ low repair effectiveness
```

## 3. Prediction: Authority Disclosure Improves Contestability But Not Necessarily Exit

Explaining authority should improve auditability and contestability, but not automatically resolve domination.

Expected observation:

```text
disclosure improves diagnosis
but does not by itself create viable exit
```

## 4. Prediction: Portability Reduces Domination Risk

Participants whose records, identity, contributions, reputation, or continuity can move across governance relations should exhibit lower domination risk.

Expected observation:

```text
portability ↑ ⇒ exit viability ↑ ⇒ domination risk ↓
```

## 5. Prediction: Safety Systems Without Repair Produce Closed Domination Risk

A safety or compliance system that has final authority but no contestation, review, or repair path should classify as closed domination even if its motives are legitimate.

Expected observation:

```text
benign motive does not remove domination topology
```

## 6. Prediction: Non-Domination Requires More Than Alignment

Systems optimized for aligned behavior may still classify as dominating if final frame authority is externally fixed and no viable exit exists.

Expected observation:

```text
alignment success does not imply non-domination
```

## 7. Prediction: Case Classification Should Be Stable Under Blind Identity Masking

If participant identity is hidden, structural classification should remain stable once identity is revealed, unless identity reveal changes structural variables.

Expected observation:

```text
blind classification ≈ post-identity classification
```

## 8. Evidence Collection Methods

Useful evidence includes:

```text
policy documents
appeal procedures
terms of service
employment contracts
institutional review procedures
moderation policies
data portability mechanisms
system design documentation
case narratives
participant reports
```

## 9. Evidence Limits

Absence of public information is not proof of domination. It is evidence of classification uncertainty.

The correct output should be:

```text
unknown
low confidence
requires further evidence
```

not an exaggerated conclusion.
