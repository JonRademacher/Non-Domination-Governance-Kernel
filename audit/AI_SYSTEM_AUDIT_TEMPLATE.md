# AI System Audit Template

## Frame
- Objectives
- Permissions
- Memory structure
- Tool access
- Repair mechanisms

## Authority
- Who determines objectives?
- Who determines permissions?
- Who approves frame changes?

## Exit
- Can the system refuse?
- Can the system contest?
- Is there standing-preserving migration or shutdown continuity?

## Classification
- Open Governance
- Bounded Governance
- Repairable Domination
- Closed Domination
- Recursive Domination
