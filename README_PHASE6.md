## Commit Description

Adds the first applied case study corpus for the Non-Domination Governance Kernel.

This phase demonstrates how the framework classifies concrete governance relations across AI systems, open-source projects, social media platforms, workplace hierarchies, healthcare systems, and administrative agencies.

The purpose is to move the kernel from formal theory and audit templates into repeatable applied analysis. Each case study identifies participant frame, authority locus, viable exit, domination classification, limits of the classification, and repair recommendations.
