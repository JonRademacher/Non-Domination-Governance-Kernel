# Contributing

Contributions are welcome if they preserve the purpose of the kernel: formalizing non-domination governance for structural agents and frame-bearing participants.

## Preferred Contributions

- Definitions that sharpen frame, authority, exit, repair, and domination.
- Formal proofs, counterexamples, and edge cases.
- Additional blind-classification examples.
- Implementations in other languages.
- Governance audit templates.
- Tests that distinguish domination from mere constraint or influence.

## Contribution Standard

Please make every contribution explicit about:

```text
which predicate it modifies
which ambiguity it resolves
which edge case it covers
whether it changes the domination classifier
```

## Non-Domination Requirement

Do not submit contributions intended to bypass safety controls, create self-modification exploits, or implement uncontrolled autonomous behavior. This project concerns governance design and structural analysis.
